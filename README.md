# RoutTech

## Sistema de Movilidad Colaborativa para la Comunidad Universitaria de la UTEQ

Repositorio correspondiente a la **Entrega 3 (2A)** del Proyecto de Fin de Curso de la asignatura **Ingeniería de Requisitos (ISR-401)**, perteneciente a la carrera de Ingeniería de Software de la Universidad Técnica Estatal de Quevedo.

RoutTech es una propuesta de plataforma web y móvil orientada a facilitar la coordinación de viajes compartidos entre integrantes adultos y verificados de la comunidad universitaria de la UTEQ. El sistema contempla búsqueda y publicación de rutas, reserva de cupos, notificaciones, historial de viajes, gestión de incidencias, reputación y recomendaciones explicables.
